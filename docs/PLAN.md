# PLAN — план разработки «Библиотека»

Вариант: бронирование книг. Стек: React + Django REST Framework + SQLite + JWT
(изначально планировался MySQL 8, см. раздел «Изменение стека» в конце).
Срок: 3 недели, 6–8 часов в неделю. Требования — `docs/SPEC.md`.

## 0. Принципы

1. Один заход агента = одна задача из плана.
2. После задачи: тесты зелёные → коммит → запись в `docs/AI_LOG.md` → экспорт
   сессии в `prompts/` и запись в `prompts/PROMPTS_LOG.md`.
3. Сначала backend и тесты, потом UI.
4. Правила (права, статусы, конфликты, очередь) — только на backend.
5. Задача считается выполненной после ручной проверки, а не после ответа агента.

## 7. Риски

| Риск | Решение |
|------|---------|
| Гонка при выдаче экземпляра | `transaction_mode="IMMEDIATE"` + тест на 10 потоков |
| Двое получили удержание | блокировка строки книги в транзакции возврата |
| Просроченное удержание блокирует фонд | проверка `hold_until` при доступности |
| Дубли в очереди | unique-проверка активной заявки на книгу |
| Отчёт теряет книги без выдач | период в `ON` у `LEFT JOIN` |
| Тест конкурентности на SQLite | файловая тестовая база (`TEST.NAME`) + `BEGIN IMMEDIATE` |
| Промпты не сохраняются | экспорт после каждой задачи |
| Секреты в истории | `.env` в `.gitignore`, проверка перед коммитом |

## 9. Изменение стека (16.11.2026)

По решению владельца проекта база данных переведена с MySQL 8 на SQLite 3:
данные должны лежать внутри проекта, без отдельного сервера.

- [x] `config/settings.py`: `django.db.backends.sqlite3`, файл `backend/db.sqlite3`,
  `transaction_mode="IMMEDIATE"`, файловая тестовая база `test_db.sqlite3`.
- [x] `requirements.txt`: убран `mysqlclient`.
- [x] `.env.example`: убраны `DB_*`; `.gitignore`: добавлен `test_db.sqlite3`.
- [x] `scripts/concurrent_booking.py`: снят запрет на не-MySQL.
- [x] Тест 10 потоков проходит на SQLite: блокировку записи даёт `BEGIN IMMEDIATE`.
- [x] Обновлены `docs/SPEC.md` (стек, инвариант, ограничения), `AGENTS.md`
  (разделы 3.1, 3.2, 3.5, 4, 7, журнал правил), `README.md`.

Ограничение: блокировок строк в SQLite нет, `select_for_update()` остаётся в коде
только ради переносимости. Параллельная запись в базу невозможна — это плата за
отказ от сервера.
